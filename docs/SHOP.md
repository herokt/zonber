# ZONBER 상점 · 코인 — v1.0 (2026-09-21)

> 원칙: **외형만 판다.** 능력치·부활 횟수처럼 기록에 영향을 주는 물건은 없다(랭킹·명패 공정성).
> 명패와 명패 테두리는 실력으로만 얻는다 — 팔지 않는다. 캐릭터 기획은 [CHARACTER_CONCEPT.md](CHARACTER_CONCEPT.md).

## 코인

| 항목 | 값 | 코드 |
|---|---|---|
| 획득 | 5초 버틸 때마다 1개(최소 1) | `CoinStore.coinsForRun` |
| 보너스 | 추가 기록 1번에 1개 — 근접 회피(STAGE 1, 링 4px) · 아슬 회피(STAGE 2, 링 5px) · 연속 선방(STAGE 3, 직전 세이브 1초 안). 난이도를 비슷하게 맞춤 | `CoinStore.bonusFor` |
| 부활로 이어진 판 | 이미 준 만큼 빼고 더 준다(중복 지급 없음) | `main._handleGameOver` · `_runCoins` |
| 광고 2배 | 결과 화면 "광고 보고 2배" — 보상형 광고 1회, 이번 판 코인을 한 번 더 | `ResultPage._doubleCoins` |
| 저장 | 로컬(SharedPreferences) + 로그인 유저는 `users/{uid}.coins`·`ownedItems` | `lib/coin_store.dart` |
| 로그인 병합 | 원격 잔액이 있으면 원격을 따른다(바뀔 때마다 원격에 쓰므로 최신). 없으면 로컬을 올린다. 보유 목록은 합친다 | `CoinStore.mergeFromRemote` |
| 로그아웃·탈퇴 | 로컬 코인을 비운다 | `CoinStore.clearLocal` |
| 표시 | 홈 상단 코인 칩(누르면 상점) · 결과 화면 · 상점 잔액 카드 | |

게스트도 코인을 모은다(로컬). 처음 로그인한 계정에 원격 값이 없으면 그대로 올라간다.
코인은 앱에서 계산한다 — 외형에만 쓰여 조작돼도 랭킹에 영향이 없다. 유료 코인 묶음을 팔게 되면 서버 검증을 붙인다.

## 상점 진입

상점 탭: **캐릭터 · 장비 · 꾸미기 · 기타**. 하단 메뉴 **홈 · 랭킹 · 상점 · 프로필**(2026-09-21 상점 탭 추가) · 홈 상단 코인 칩 · 프로필의 변경권 안내.

| 기타 | 닉네임 변경권 · 국가 변경권 | 150 | 코인 구매 |
| | 광고 제거 | 인앱 결제 | 준비 중 — `IAPService` 가 앱에서 초기화되지 않은 상태 |

캐릭터 해금 = 기본 · 업적 달성 · 코인 구매 중 하나(`CharacterData.isUnlocked`). 보유 id 는 `char_{id}`.

꾸미기(`lib/cosmetics.dart`)는 전부 코드로 그린다(이미지 없음). 게임(`Player` 잔상 입자·오라)과 상점 미리보기가 같은 그리기 함수를 쓴다 — 보이는 그대로 산다.
착용 정보는 `users/{uid}.equipped`(슬롯 → id).
장비는 `lib/gear.dart`(목록·보너스) + `lib/gear_painter.dart`(그림·상점 아이콘 `GearIconPainter`). 착용 슬롯 `gear_{존}_{부위}`.
판정·히트박스에는 영향이 없다.
