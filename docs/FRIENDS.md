# ZONBER 친구 — v1.0 (2026-09-30)

> 친구를 맺고, 친구 기록과 비교하며 서로 도전하게 한다. "친구가 내 기록을 깼다" 알림의 바탕.
> 예전 친구 코드(코인 보상 한 번)는 그대로 두고, 그 위에 **누가 친구인지 기억하는** 목록을 얹는다.

## 1. 친구 맺는 법

| 방법 | 흐름 | 이유 |
|---|---|---|
| **친구 코드 입력** | 코드를 넣으면 **바로 서로 친구** | 코드를 알려 준 것 자체가 동의. 공유 링크로 들어온 친구도 이 길 |
| **친구 요청** | 랭킹·프로필 카드에서 "친구 요청" → 상대가 **수락**하면 친구 | 모르는 사람 — 받는 쪽이 고른다 |

- 코드 보상(처음 한 번, 넣은 사람·코드 주인 코인 200)은 예전 그대로. 친구 추가는 보상 없이 여러 번 된다.
- 코드는 친구 화면의 "코드로 추가" 칸이나 이벤트 화면 코드 칸 어디에 넣어도 된다.
- 서로 요청을 보냈으면(내가 받은 요청이 있는 사람에게 요청) 바로 친구가 된다.

## 2. 화면

- **프로필 탭 › 친구 N명** → 친구 화면: 내 친구 코드(복사·공유) · 코드로 추가 · 받은 요청(수락·거절) · 친구 목록
  - 목록은 고른 존의 최고 기록 순(= 친구 랭킹), 내 줄은 강조, 친구를 누르면 프로필 카드(기록 · 이 기록 깨러 가기 · 친구 삭제)
- **랭킹 탭** 세계 | 국가 | **친구** — 기간(주·월·올해)도 그대로 적용
- **프로필 카드**(랭킹에서 이름을 누르면): 친구 요청 / 요청 보냄 / 수락 / 친구(삭제)
- 게스트: 친구 화면은 보이지만 로그인 안내만(게스트는 아무것도 저장하지 않는다)

## 3. 제한

| | 값 | 어디 |
|---|---|---|
| 친구 수 | 최대 100명 | `functions/friends.js` `MAX_FRIENDS` · `lib/friends.dart` |
| 보낸 요청(대기) | 최대 50개 | `MAX_PENDING` |
| 요청 유효 | 7일 | `REQUEST_DAYS` |
| 거절 뒤 다시 요청 | 7일 뒤부터 | `COOLDOWN_DAYS` |
| 친구 기록 알림 | 친구 한 명당 하루 1번 · 모두 합쳐 하루 3번 | `functions/friends.js` |

공개되는 정보는 닉네임·국기·아바타·기록뿐(랭킹과 같다). 차단은 v1 에 없다 — 거절·삭제·요청 제한으로 본다.

## 4. 알림

| 종류 | 받는 사람 | 문구(ko) |
|---|---|---|
| `friend_request` | 요청 받은 사람 | 👋 ○○님이 친구 요청을 보냈어요 |
| `friend_accepted` | 요청 보낸 사람 | 🤝 ○○님이 친구 요청을 수락했어요 |
| `friend_added` | 코드 주인 | 🤝 ○○님이 내 친구 코드로 친구가 됐어요 |
| `friend_beat` | 기록을 넘긴 친구들 | 🔥 ○○님이 피구에서 내 기록(96.212초)을 넘었어요. 되찾으러 가기! |

- 문구는 받는 기기의 언어로(4개 언어) — `functions/notify.js`
- **친구 기록 알림** = 친구가 그 존에서 **처음으로** 내 최고 기록을 넘은 순간(친구의 이전 최고 < 내 최고 < 이번 기록)
- 개인에게 보내야 해서 **기기 알림 주소(토큰)를 저장**한다: `users/{uid}/devices/{기기 id}` — 본인만 읽고 쓴다.
  로그아웃하면 지운다. 설정 › **친구 알림**을 끄면 친구 알림만 안 온다(이벤트·소식 알림과 따로)
- 알림은 **알림함**(`users/{uid}/inbox`)에 늘 남는다 — 앱 알림 페이지(홈 위 종 아이콘)에서 읽음/안 읽음으로 본다. 설정·기기와 상관없다
- 푸시는 **30분 안에 못 받으면 버린다**(TTL) — 폰이 꺼져 있다 켜져도 지난 알림이 쏟아지지 않는다(알림함에는 남아 있다).
  같은 친구의 같은 종류 알림이 쌓이면 최신 하나만 온다(collapse)
- 알림을 누르면 알림 페이지가 열린다

## 5. 데이터 · 서버 함수

```
users/{uid}/friends/{친구uid}      {since, via: code|request}   양쪽에 한 건씩 · 본인만 읽기 · 앱은 못 쓴다
friend_requests/{보낸uid_받는uid}  {from, to, status: pending|declined, at, expiresAt, decidedAt}
users/{uid}/devices/{기기 id}      {token, lang, platform, friend, updatedAt}
push_state/{uid}                   알림 하루 횟수(서버만)
```

상대 목록에 나를 넣는 일은 앱에서 안전하게 할 수 없어서 **서버 함수가 쓴다**(`functions/friends.js`, us-central1):

| 함수 | 하는 일 |
|---|---|
| `addFriendByCode(code)` | 코드 주인과 바로 친구 + 코드 주인에게 알림 |
| `sendFriendRequest(uid)` | 요청(상대가 먼저 보냈으면 바로 친구) + 받는 사람에게 알림 |
| `answerFriendRequest(uid, accept)` | 수락 → 친구 + 보낸 사람에게 알림 / 거절 → 7일 재요청 막기 |
| `removeFriend(uid)` | 양쪽에서 지우기 |
| `onRecordCreated` | 새 랭킹 기록 → 넘긴 친구에게 `friend_beat` |
| `onUserDeleted` | 탈퇴 → 친구·요청·기기 정리 |

결과는 문자열 코드로 돌려준다(`added` · `requested` · `already` · `not_found` · `self` · `my_limit` · `their_limit` · `too_many` · `cooldown` · `expired` …) — 앱 `FriendResult` 와 같다.

**색인**: 랭킹 기록 `userId + timestamp`(친구 랭킹) · `userId + survivalTime↓`(친구 기록 알림).
