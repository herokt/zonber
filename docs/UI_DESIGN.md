## 1. 디자인 원칙

| 원칙 | 의미 | 지금과 다른 점 |
|---|---|---|
| **무대는 어둡고, 주인공은 하나** | 배경·서피스는 무채색 다크. 화면당 강조색은 현재 월드 색 1개 | 시안 네온 글로우가 모든 요소에 걸려 있던 것을 제거 |
| **숫자가 곧 UI** | 생존 시간·순위는 화면에서 가장 큰 요소. 타뷸러 숫자, 밀리초까지 | 타이틀·장식이 숫자보다 컸음 |
| **리더보드가 종착지** | 홈·게임·결과·프로필 어디서든 "내 순위/다음 목표"가 보인다 | 랭킹은 메뉴의 버튼 하나였음 |
| **명패는 영구적이다** | 한 번 도달한 최고 순위는 프로필에 명패로 남는다. 밀려나도 사라지지 않는다 | 현재는 실시간 순위만 존재, 밀려나면 흔적 없음 |
| **3탭 안에 플레이** | 첫 실행: 앱 열기 → START → 플레이. 로그인·국가·튜토리얼은 뒤로 | 로그인 강제(구 Android), 아이템 가이드 등 |
| **플랫, 두께 있는 카드, 넉넉한 여백** | 20px 라운드, 1px 반투명 테두리, 그림자 최소. 글래스·그라데이션 워시 없음 | 글로우·블러·네온 라인 |

## 2. 비주얼 시스템 (design_system.dart 교체 스펙)

### 2.1 색

> **v2.1 라이트(2026-09-18):** 어두운 컨셉을 버리고 밝고 가벼운 팔레트로 교체. 무대(게임 바닥)만 스테이지 색을 유지한다(Cyber는 네온이 읽히도록 짙은 남색).

```
배경        bg        #F6F7FB      오프화이트
서피스 1    surface   #FFFFFF      카드 기본
서피스 2    surface2  #EDF0F5      카드 안의 카드 / 입력 / 세그먼트
테두리      line      rgba(15,23,42,0.08)
텍스트      text      #0F172A      슬레이트
보조 텍스트 textDim   #64748B      (흰 배경 4.6:1)
성공/경신   up        #16A34A
경고/피격   danger    #E5484D
골드(명예)  gold      #C99700      명패·챔피언·의식 화면 전용. 명패 바탕은 크림 #FFF4CC
```

**월드 강조색** (카드·START·HUD·경고에 그 월드만 사용)

| 월드 | accent | 보조(바닥/무대) |
|---|---|---|
| Dodgeball | `#E5484D` | 밝은 마루 `#E9CFA6` |
| Baseball | `#3DD68C` | 잔디 `#16351F` |
| Soccer | `#4C8DFF` | 잔디 `#123A2A` |
| Cyber | `#0A9DBD` (UI) | 짙은 남색 무대 `#141A33`, 탄은 네온 그대로 |
| Zombie | `#A3F94C` | 아스팔트 `#15171B` |

### 2.2 타이포

- **Display:** Sora (700/800) — 타이틀, 생존 시간, 순위. 숫자는 `tabular-nums`.
- **Body:** Manrope (500/600/700) — 본문, 버튼, 라벨.
- Orbitron은 Cyber 월드 **내부 무대**(HUD 장식)에만 남기고 앱 UI에서 제거.
- 스케일: 12 / 14 / 16 / 20 / 28 / 40 / 64(생존 시간) / 96(순위 의식).

### 2.3 컴포넌트

| 컴포넌트 | 스펙 |
|---|---|
| Card | surface, radius 20, border line, padding 20 |
| Button primary | 높이 56, radius 16, 월드 accent 배경, 텍스트 `#0B0D12` 700 |
| Button secondary | 높이 48, radius 14, surface2 배경, 텍스트 text |
| Chip | 높이 28, radius 999, surface2, 12px 600 |
| Segmented | 높이 36, radius 12, 선택 항목 surface2 + text, 나머지 textDim |
| World tab | 높이 36, radius 999, 선택 = 월드 accent 배경 |
| Rank row | 높이 56, 순위(24px Display) · 아바타 28 · 이름 · 국가 칩 · 시간(타뷸러, 우측) |
| Name plate(명패) | 342×120, gold 테두리 1.5px, 안쪽 어두운 금속 `#2A2412`, 각인 텍스트 gold, 모서리 리벳 4개 |
| Bottom nav | 높이 64+safe, 3탭(홈 · 랭킹 · 프로필), 선택 아이콘 accent |

아이콘: Material Rounded 계열 라인 아이콘 1세트로 통일(이모지 사용 금지, 국기는 ISO 2자 칩 + 국기 이미지).

**아바타 = 선택한 캐릭터 스프라이트.** 사진 업로드는 없다(스토리지·검수·심사 부담). 홈·프로필은 내 캐릭터, 랭킹 행은 그 기록의 `characterId`를 그린다. 명패 보유자는 아바타 테두리만 gold.

## 3. 정보 구조

```
[Home] ──── START ───→ [Game] ──── 게임 오버 ───→ [Result]
  │                                                 │ 순위권 진입
  │ 카드 탭                                          ├─→ [Hall of Fame 의식] → 공유 / 랭킹
  ├─→ [World Sheet] ── START ──→ [Game]              │ 게스트 & 순위권
  │                                                 └─→ [Result: 잃어버린 순위] → 로그인
  ├─→ [Ranking]  (하단 탭)  ── 월드 탭 × 기간 × 세계/국가, 명예의 전당
  └─→ [Profile]  (하단 탭)  ── 명패, 월드별 기록, 캐릭터, 설정, 로그인/로그아웃
```

- 현행 `_currentPage` 문자열 라우팅은 유지. `Menu`→`Home`, 새 페이지 `WorldSheet`(바텀시트, 페이지 아님), `HallOfFame`, `Ranking`(다이얼로그→탭 페이지).
- 하단 탭은 Home / Ranking / Profile 3개. Shop은 IAP 재개 전까지 프로필 안의 행 하나.

## 4. 화면별 기획

### 4.1 Home (목업 `Home`)

| 영역 | 내용 |
|---|---|
| 상단 바 | 아바타 + 닉네임 + 국가 칩 / 우측 설정. **게스트면** 아바타 자리에 점선 원 + "게스트" 라벨, 아래 1줄 배너 "기록은 랭킹에 남지 않아요 · 로그인" |
| 월드 캐러셀 | 가로 스와이프 카드 342×300, 양옆 카드가 24px 살짝 보임. 카드 = 월드 무대 일러스트(상단 60%) + 이름 + 한 줄 판타지 + **내 최고 기록** + **내 순위 칩(세계 #N · 국가 #N)**. 잠긴 월드는 무대가 어둡고 자물쇠 + "Dodgeball 60초 생존 시 해금". 페이지 도트 5개 |
| 캐릭터 행 | 스프라이트 원 40 + 이름 + 스탯 점 4개 + "변경 ›" |
| START | 56px, 월드 accent. 아래 12px 보조 "Dodgeball · 세계 12,480명 참가 중" (참가자 수 = 그 월드 올해 레코드 유저 수, 규모감을 준다) |
| 하단 탭 | 홈(선택) · 랭킹 · 프로필 |

첫 실행: 캐러셀은 Dodgeball에 고정되고 START만 강조(다른 요소는 40% 투명도, 첫 게임 오버 후 정상 노출).

### 4.2 World Sheet (목업 `WorldSheet`)

카드 탭 → 바텀시트(높이 88%). 룰 3줄(아이콘 + 한 문장), "이 월드의 공"(투사체 2~3종: 아이콘 · 이름 · 거동 한 줄), **TOP 3 미니 포디움**(아바타·이름·시간), 내 최고/순위 행, START. 랭킹으로 가는 텍스트 링크 "전체 순위 보기 ›".

### 4.3 Game HUD (목업 `Game`)

| 영역 | 내용 |
|---|---|
| 상단 좌 | 일시정지(44px 터치 영역) |
| 상단 중앙 | 생존 시간 40px Display 타뷸러 `01:32.4` |
| 상단 우 | 에너지 핍(캐릭터 최대치만큼, 채워진 칸 accent) |
| **목표선** | 타이머 아래 4px 바. 좌측 "다음 목표 TOP 100 · 1:45.2", 바는 현재 시간/목표 시간 비율. 목표 통과 시 바가 gold로 0.6초 번쩍이고 다음 목표(TOP 30 → TOP 10 → #1)로 교체. **리더보드를 플레이 중에 끌어들이는 장치.** 게스트도 표시(순위는 등록 안 되지만 "어디쯤인지"는 보인다) |
| 무대 | 480×768 아레나, 월드 바닥·라인. 진입 경고는 월드 판타지대로(와인드업·총구 점등·문 덜컹) |
| 하단 | 근접 회피 카운터 `GRAZE ×12` 12px, 콤보 시 살짝 커짐. 광고 배너는 **게임 중 숨김** |

개인 최고 경신 순간: 타이머 색이 `up`으로 바뀌고 "BEST" 12px 라벨이 옆에 붙는다. 소리 1회.

### 4.4 Result (목업 `Result`)

두 단계다. **A. 결과 카드** → (조건 충족 시) **B. 의식 화면**.

A. 결과 카드
- "GAME OVER" 12px, 생존 시간 64px Display, 개인 최고 대비 델타 칩(`+3.2s 개인 최고 경신` / `-12.1s`).
- 스탯 행: 레벨 · 근접 회피 · 캐릭터.
- **순위 카드**(핵심): "세계 #1,204 / 12,480명 · 한국 #37 / 812명" + "TOP 100까지 57.4초". 순위는 등록 전 미리 계산해 보여준다(등록은 로그인 유저만 자동).
- 버튼: 다시하기(primary) / 부활 · 광고 1회(secondary, 남은 횟수) / 홈.
- **게스트 변형:** 순위 카드가 "이 기록은 세계 #1,204였습니다. **로그인하면 이름이 새겨집니다**" + 로그인 버튼(primary). 기록은 사용자 결정대로 남기지 않는다. 다만 잃은 순위를 숫자로 보여주는 게 전환의 핵심이다.

B. Hall of Fame 의식 (목업 `HallOfFame`) — 등록 결과가 **세계 TOP 100 또는 국가 TOP 10 또는 기간(일/주/월) 1위**면 진입
- 화면 전체 어두워지고 gold만 남는다. 상단 "당신의 이름이 새겨졌습니다".
- **명패** 342×120이 아래에서 올라오며 이름이 한 글자씩 각인(0.8초, 각인 SFX + 햅틱 3연타). 명패 내용: 닉네임 · 국가 · 월드 · 순위 · 날짜.
- 순위 숫자 96px가 큰 수에서 실제 순위로 카운트다운(1.2초).
- "12,480명 중" 14px, 아래 "이 명패는 프로필에 영구 보존됩니다".
- 버튼: 공유하기(gold primary) / 랭킹 보기(secondary). 공유 카드는 명패 그대로 1080×1920 이미지.
- 기간 1위(오늘의 챔피언)면 명패 상단에 리본 "TODAY'S CHAMPION · DODGEBALL".

### 4.5 Ranking (목업 `Ranking`)

| 영역 | 내용 |
|---|---|
| 월드 탭 | 가로 칩 5개, 선택 = 월드 accent. 잠긴 월드도 볼 수는 있다(동기 부여) |
| 기간 | 세그먼트: 오늘 · 이번 주 · 이번 달 · 올해 |
| 범위 | 토글: 세계 / 내 국가 |
| 포디움 | TOP 3. 중앙 #1이 가장 높고 gold 왕관, #2 은, #3 동. 아바타 56 · 이름 · 국가 칩 · 시간 |
| 리스트 | #4~#30 Rank row. 내 행은 accent 테두리로 강조 |
| **내 행 고정** | 리스트 밖이면 하단에 고정 바 "#1,204 JARVIS 47.812 · TOP 100까지 57.4s" |
| 명예의 전당 | 리스트 위 카드 1장: "역대 챔피언" — 이 월드 올해 #1 명패 미니 + "일간 챔피언 아카이브 ›"(날짜별 1위 목록, 영구) |

참가자 수를 항상 표기한다("12,480명"). 순위의 무게는 분모에서 나온다.

### 4.6 Profile (목업 `Profile`)

| 영역 | 내용 |
|---|---|
| 헤더 | 아바타 64 · 닉네임 · 국가 · 편집. 게스트면 로그인 카드가 헤더를 대신한다("로그인하면 기록이 랭킹에 남고 명패를 받을 수 있어요") |
| **내 명패** | 가로 스크롤. 월드별 최고 도달 순위 명패(도달한 것만). 없으면 빈 명패 실루엣 + "Dodgeball TOP 100에 들면 첫 명패" |
| 월드별 기록 | 5칸 그리드(2열): 월드 아이콘 · 최고 시간 · 현재 세계 순위 · 잠금 |
| 캐릭터 | 6개 원형, 잠긴 건 흑백 + 조건 |
| 설정 | 사운드 · 진동 · 감도 · 언어 · 통계 · 로그아웃/계정 삭제 · 앱 버전 |

### 4.7 Login (별도 목업 없음)

현행 구조 유지, 스타일만 교체. 제목 "이름을 새기려면 계정이 필요해요", Google / Apple(iOS), 아래 "게스트로 계속하기" + "게스트 기록은 랭킹에 저장되지 않아요". 결과 화면에서 온 경우 상단에 방금 기록 카드("47.812s · 세계 #1,204")를 보여줘 **무엇을 얻는지** 상기시킨다.

### 4.8 첫 실행 온보딩

튜토리얼 화면 없음. 첫 게임 시작 직후 2초간 무대 위에 손가락 아이콘 + "드래그해서 피하세요" 오버레이(터치하면 즉시 사라짐). 첫 게임 오버의 결과 카드에 "TOP 100까지 N초" 목표선이 처음 등장한다.

## 5. "내 이름이 올라간 것"을 굉장한 일로 만드는 장치 (요약)

| 장치 | 화면 | 효과 |
|---|---|---|
| 목표선(다음 순위 구간) | Game HUD, Result | 플레이 중 리더보드가 목표가 된다 |
| 순위 미리 계산 + 분모 표기 | Result, Ranking | "#1,204 / 12,480명" — 규모가 무게를 만든다 |
| Hall of Fame 의식 | Result B | 각인 애니·소리·햅틱·카운트다운. 하루 1회 이상 보기 어렵게 조건을 잡는다 |
| 영구 명패 | Profile, 공유 카드 | 밀려나도 "최고 도달 #87 · 2026.09.18"은 남는다 |
| 일간 챔피언 아카이브 | Ranking | 하루 1위는 영원히 기록된다 — 매일 새 기회 |
| 게스트의 잃어버린 순위 | Result(게스트) | 등록 못 한 순위를 숫자로 보여줘 로그인 전환 |
| 포디움 · 왕관 · gold 전용색 | Ranking | gold는 여기서만 쓰여 희소성을 유지 |

데이터 요구(구현 시): `users/{uid}.plates[worldId] = {bestRank, total, date, period}`, `maps/{worldId}/champions/{YYYY-MM-DD}` 일간 챔피언 스냅샷(리셋 시 Cloud Function 또는 첫 조회 클라이언트가 기록), 참가자 수 카운터 `maps/{worldId}.entrants[period]`.

## 7. 구현 순서 (UI만)

1. `design_system.dart` 토큰·컴포넌트 교체(색·폰트·Card·Button·Chip·Segmented·RankRow·NamePlate·BottomNav). 기존 화면이 새 토큰으로 자동 갈아입는다.
2. Home 재구성(월드 캐러셀·하단 탭) — 월드 골격(WorldConfig)과 같은 배포.
3. Result A + 순위 미리 계산 + 게스트 변형.
4. Game HUD 목표선 + 근접 회피 카운터.
5. Ranking 탭 페이지(포디움·내 행 고정·명예의 전당).
6. Hall of Fame 의식 + 명패 데이터 + 공유 카드.
7. Profile(명패·월드별 기록).

## 8. 열린 결정

- Hall of Fame 진입 조건(세계 TOP 100 / 국가 TOP 10 / 기간 1위)의 숫자. 참가자가 적은 초기에는 TOP 100이 너무 쉬울 수 있어 **참가자 수의 상위 1%와 100 중 작은 값**을 제안.
- 일간 챔피언 스냅샷을 Cloud Function으로 할지(정확, 비용) 클라이언트 첫 조회로 할지(무료, 누락 가능).
- 국기: 이모지 대신 국기 이미지 세트를 넣을지(이모지는 Android 기종별 렌더 차이).
